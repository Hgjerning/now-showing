# Input data

Licensed and third-party price data are not in this repo. Put the files below in this folder
(or point `P10_DATA` at your Sharadar copy for the stock-level articles) and the code runs unchanged.

| file | source |
|---|---|
| `GSPC_daily_close.csv` | S&P 500 index (^GSPC) daily close, Yahoo Finance. Not redistributed. |
| `N225_daily_close.csv` | Nikkei 225 (^N225) daily close, Yahoo Finance. Not redistributed. |
| `ixic.csv` | Nasdaq Composite (^IXIC) daily, Yahoo Finance. Not redistributed. |
| `us_monthly_adjclose_panel.csv` | Monthly adjusted closes per stock, Yahoo Finance. Not redistributed. |
