# Input data

Licensed and third-party price data are not in this repo. `code/download_data.py` fetches the Yahoo series; save Shiller's `ie_data.xls` by hand from shillerdata.com and run `code/v2_download.py`. `SHA256SUMS` holds the hashes of the files used.

|---|---|
| `us_presidential_elections.csv` | Included. US presidential election years and winning party. |
