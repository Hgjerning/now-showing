# Input data

Licensed and third-party price data are not in this repo. Put the files below in this folder
(or point `P10_DATA` at your Sharadar copy for the stock-level articles) and the code runs unchanged.

| file | source |
|---|---|
| `aqr_qmj_qmj_factors.csv` | AQR data library: Quality Minus Junk factors. |
| `art_recipes_gate.csv` | Derived from the author's private or licensed data. Not redistributed. |
| `factor_recipes_results.csv` | Derived from the author's private or licensed data. Not redistributed. |
| `french_developed_5f_daily.csv` | Kenneth R. French Data Library (Tuck/Dartmouth): download the named factor files. |
| `french_developed_mom_daily.csv` | Kenneth R. French Data Library (Tuck/Dartmouth): download the named factor files. |
| `french_us_5f_daily.csv` | Kenneth R. French Data Library (Tuck/Dartmouth): download the named factor files. |
| `french_us_mom_daily.csv` | Kenneth R. French Data Library (Tuck/Dartmouth): download the named factor files. |
| `guru_factor_attribution.csv` | Derived from the author's private or licensed data. Not redistributed. |
| `jkp_usa_factors_monthly.csv` | Jensen, Kelly & Pedersen factor data (jkpfactors.com): download the USA/World factor returns. |
| `jkp_world_factors_monthly.csv` | Jensen, Kelly & Pedersen factor data (jkpfactors.com): download the USA/World factor returns. |
