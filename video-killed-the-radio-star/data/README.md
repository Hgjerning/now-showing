# A08 data (not redistributed)

- `jkp_usa_factors_monthly.csv`: Jensen, Kelly & Pedersen US factor returns (capped value-weighted tercile long-short,
  monthly), downloaded from jkpfactors.com. Use their terms of use.
- `Factor Details.xlsx`: JKP's factor-details table, from github.com/bkelly-lab/ReplicationCrisis (GlobalFactors).

Put both files here, then run the scripts listed in the article's "Reproduce" section.
